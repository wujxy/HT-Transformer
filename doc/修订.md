# 面向 JUNO 球形光学探测器的径迹端点重建

## Transformer 架构与训练实施报告（修订版）

---

## 一、执行摘要

本项目针对 JUNO（Jiangmen Underground Neutrino Observatory）球形液体闪烁体探测器中**径迹端点重建问题**，设计并实现一套可工程落地的 Transformer 架构。任务目标为：根据 PMT 的空间分布与时间响应，预测粒子径迹与球面的两个交点（入射点与出射点）。

考虑 JUNO 探测器的结构特性（CD ≈ 17612 PMTs，WP ≈ 2400 PMTs），以及：

* 球面拓扑结构
* 局部高密度响应 + 全局长程依赖
* 多峰时间结构

本项目采用如下主线架构：

> **Hybrid Token Transformer（CD patch + WP hit）
>
> * Two-Level Time CD 表示
> * 局部球面稀疏注意力（kNN）
> * Global Token 全局交互
> * 双端点有序回归**

相较于原始方案，本修订版关键改动为：

* 输出改为**有序双端点单位向量**
* 引入**方向一致性约束**
* Loss 重构为：

  * 角度损失（主）
  * 端点间距离约束
  * 方向约束
* 固定使用 **Global token** 作为长程交互方案
* 时间输入直接使用**相对触发时间（不再二次对齐）**
* 基线阶段：

  * ❌ 不注入噪声
  * ❌ 不启用旋转增强

起步模型规模：

| 参数      | 数值  |
| ------- | --- |
| d_model | 128 |
| 层数 L    | 4   |
| heads   | 4   |
| d_ff    | 512 |

## 二、问题定义与目标

### 2.1 输入定义

一个事件由 hit 集合构成：

[
(x_i, q_i, t_i)
]

其中：

* (x_i \in \mathbb{R}^3)：PMT 坐标（球面）
* (q_i \ge 0)：电荷
* (t_i)：相对于事件触发时间的相对击中时间

---

### 2.2 输出定义（核心修订）

模型输出：

[
\hat{\mathbf u}_1, \hat{\mathbf u}_2 \in S^2
]

* 均为单位向量
* **有序定义：**

  * (\mathbf u_1)：粒子传播方向上的**第一个交点**
  * (\mathbf u_2)：第二个交点

👉 不再使用 permutation-invariant / Hungarian matching
👉 改为**有序回归问题**

---

### 2.3 任务目标

模型需同时满足：

1. **端点位置准确**
2. **径迹长度合理**
3. **方向一致性正确**

---

## 三、数据与预处理

### 3.1 Token 化策略

#### WP（Water Pool）

* 每个 hit → 一个 token
* 保留完整时间信息

#### CD（Central Detector）

* 使用 HEALPix 进行球面 patch 划分
* 每个 patch → 一个 token

---

### 3.2 CD 两级时间表示（核心）

#### 一级统计量：

* sumQ
* count
* t_min
* t_mean（charge 加权）

#### 二级时间结构（关键创新）：

构造 time-bin 序列：

[
s[b] = \sum q_i, \quad t_i \in bin(b)
]

* 推荐：**B = 32**
* 备选：16 / 64

---

### 3.3 时间处理（重要修订）

当前设定：

> 所有 hit time 已为相对触发时间

因此：

* ❌ 不再做 (t - t_{min})
* ❌ 不做 quantile 对齐
* ✔ 仅做归一化 / clip

---

### 3.4 数据增强策略

当前版本（基线）：

| 方法              | 是否启用 |
| --------------- | ---- |
| 旋转增强            | ❌    |
| time jitter     | ❌    |
| drop hits       | ❌    |
| noise injection | ❌    |

👉 全部关闭，仅保留接口

---

## 四、输入表示与位置编码

### 4.1 Token 表示

#### WP token

[
[u_x, u_y, u_z, q, t]
]

#### CD token

[
[u, sumQ, count, t_{min}, t_{mean}, s[1..B]]
]

---

### 4.2 类型嵌入

[
\tau \in {WP, CD, GLOBAL, QUERY}
]

---

### 4.3 位置编码方案

---

### 方案 A：绝对球面位置编码

基于：

[
u = (x,y,z)
]

方法：

* Fourier features（推荐）
* 或 MLP

**优点：**

* 简单
* 稳定
* 低成本

**缺点：**

* 不表达 token 间关系

---

### 方案 B：相对位置编码（RPE）

定义：

[
\alpha_{ij} = \arccos(u_i \cdot u_j)
]
[
\Delta t_{ij} = |t_i - t_j|
]

注入 attention：

[
score_{ij} += b(\alpha_{ij}, \Delta t_{ij})
]

---

### 4.4 最终选择

> ✅ **绝对 PE + 相对 RPE（双轨）**

* Absolute：提供位置
* RPE：提供结构

## 五、Transformer 主干与混合注意力模块

### 5.1 架构

```
Tokens → Encoder → 2 Query → Endpoint Heads
```

---

### 5.2 注意力结构

| 连接          | 类型     |
| ----------- | ------ |
| WP ↔ WP     | 全连接    |
| WP ↔ CD     | 全连接    |
| CD ↔ CD     | kNN 局部 |
| Query ↔ All | 全连接    |

---

### 5.3 CD 局部注意力

* kNN based（球面角距）
* 推荐：k = 16

复杂度：

[
O(Nk) \ll O(N^2)
]

---

### 5.4 长程交互（修订）

> ✅ 统一采用 **Global Token**

* 数量：M = 4 或 8
* 与所有 token 交互

❌ 不使用：

* ISAB（暂不）
* 周期全局层（暂不）

---

## 六、输出头设计

### 6.1 单位向量回归

每个 query 输出：

[
v \rightarrow \hat u = \frac{v}{||v||}
]

优点：

* 自动落在球面
* 无角度奇异性

---

### 6.2 不确定性建模

当前版本：

* ❌ 不使用 vMF

未来可扩展：

* vMF 分布
* MC Dropout

## 七、损失函数设计（核心）

---

### 7.1 角度损失（主损失）

[
\alpha_k = \arccos(\hat u_k \cdot u_k)
]

[
L_{ang} = \frac{1}{2}(\alpha_1 + \alpha_2)
]

---

### 7.2 弧长解释

[
L_{arc} = R \cdot L_{ang}
]

👉 等价，不单独优化

---

### 7.3 径迹长度约束（关键新增）

[
L_{len} = SmoothL1(||\hat u_2 - \hat u_1||, ||u_2 - u_1||)
]

作用：

* 防止径迹塌缩
* 保证长度正确

---

### 7.4 方向一致性约束（关键新增）

[
\hat d = \frac{\hat u_2 - \hat u_1}{||\cdot||}
]

[
L_{dir} = 1 - \hat d \cdot d
]

---

### 7.5 总损失

[
L = \lambda_{ang}L_{ang}

* \lambda_{len}L_{len}
* \lambda_{dir}L_{dir}
  ]

推荐：

| 项         | 权重   |
| --------- | ---- |
| angle     | 1.0  |
| length    | 0.5  |
| direction | 0.25 |
